# 🚴‍♂️ Bike Store Dashboard - Excel Data Analysis Project

This project presents a complete data analysis workflow for a bike store using **Microsoft Excel**.  
It includes everything from **data cleaning** to building an **interactive dashboard**.

---

## 🧠 Project Overview

The goal of this project was to analyze bike sales data to uncover business insights, such as:

- Which customer segments are more likely to purchase?
- Is there a correlation between income and bike ownership?
- Does commute distance affect purchasing behavior?
- Performance analysis by region and education level

---

## 🛠️ Tools & Skills Used

- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Data Cleaning  
- Conditional Formatting  
- Slicers and Filters  
- Dashboard Design & Visualization
